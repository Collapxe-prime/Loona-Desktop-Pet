# История изменений

## 1.0.0 — 2026-10-07

Первая версия Loona Desktop Pet — самостоятельного анимированного питомца для Windows.

### Возможности

- Loona гуляет по рабочему столу, иногда бегает и выполняет другие случайные
  действия: достаёт телефон или садится на окно.
- ПКМ открывает меню. Перетаскивание ЛКМ позволяет перемещать питомца и бросать его.
- Loona реагирует на курсор и набор текста. Поглаживание вызывает улыбку и сердечки;
  после поглаживания дольше четырёх секунд проигрывается один цикл злости.
- Взаимодействие с окнами учитывает инерцию, скольжение, падение и восстановление
  равновесия.

### Анимации и поведение

- Обновлены кадры ходьбы с чередованием фаз ног в обоих направлениях.
- Обновлены кадры бега; сохранены прежний темп и привязка к движению.
- Усилено сцепление с движущимся окном во время сидения.
- Приветствие и проверочная последовательность заканчиваются позой ожидания.

### Сборка для Windows

- Добавлена локальная сборка PyInstaller для Windows x64 на Python 3.12.
- Сборка создаёт папку с приложением и ZIP-архив. Эти артефакты не публикуются
  автоматически как GitHub Release.
