# Changelog

Изменения записываются вручную. Номер собираемой версии хранится только в `VERSION`.
Версия `1.0.0` подготовлена к релизу; эта запись не подтверждает его публикацию.

## Unreleased

### Added

- Значок в системном трее: ЛКМ возвращает Loona на монитор курсора, ПКМ открывает
  меню; значок восстанавливается после перезапуска Проводника и удаляется при выходе.
- Команда «Вернуть Loona на экран» сбрасывает перетаскивание, инерцию и старую опору.
- Переключатель автозагрузки при входе в Windows для .exe, выключенный по умолчанию;
  повторный запуск возвращает существующего питомца вместо создания второго.

### Changed

- Ходьба привязана к измеренным смещениям опорной стопы: 157,4 px на полный
  цикл при размере 100% и индивидуальные расстояния между кадрами вместо
  равномерного перебора. Рисунки, ручные тайминги, скорость перемещения и бег сохранены.
- Исправлена привязка бега к расстоянию: полный 16-кадровый набор содержит два
  повторения шага и теперь покрывает 230,4 px при размере 100%, вместо 115,2 px.
  Скорость перемещения, тайминги ручного проигрывания и ходьба сохранены.
- Исправлен слишком медленный темп нового комплекта: цикл бега 640 мс,
  ходьбы 1280 мс по метаданным дизайнера; расстояние на цикл согласовано
  с действующей скоростью перемещения, сами рисунки не изменены.
- Подключён предоставленный комплект ходьбы v6 и бега v5 с новой мимикой:
  по 16 полных кадров в каждом направлении, с сохранением скорости перемещения;
  чёткость согласована с остальными группами.
- Для гримуара и работы прежний темп 1/3× стал новым 1×: базовые длительности
  кадров увеличены втрое. Старые настройки автоматически переводятся на новую
  шкалу без изменения фактического темпа; перенос выполняется однократно.

### Maintenance

- В Git-копии готовое приложение находится в корне, исходники перенесены в
  `Loona-Desktop`; синхронизация обновляет оба слоя из Dev и проверенной сборки.
- Синхронизация Dev → Git заменяет управляемые исходники и удаляет устаревшие
  файлы, сохраняя `.git`, настройки GitHub и артефакты релизов; состав и содержимое
  зеркала проверяются после переноса.

## 1.0.0 — подготовлено 2026-10-07

### Added

- Самостоятельный desktop-питомец Loona для Windows с меню, перетаскиванием и броском.
- Реакции на курсор и набор текста, поглаживание с улыбкой и сердечками.
- Однократная злость после прекращения поглаживания длительностью более четырёх секунд.
- Случайные прогулки, редкие пробежки, телефон и длительное сидение на окнах.
- Физика оконных опор, инерция, скольжение, падение и восстановление баланса.
- Единый номер версии, правила Git и локальный сценарий сборки Windows.
- Имя Loona Desktop Pet, EXE `LoonaDesktopPet.exe`, иконка дизайнера с семью
  размерами и Windows version info с версией 1.0.0; проверка branding при сборке ZIP.

### Changed

- Исправлены последовательности ног в ходьбе и беге.
- Приветствие и проверка заканчиваются позой idle.
- Усилено сцепление с окном в сидячей позе.
- Для собранного приложения настройки и лог отделены от файлов установки.
- Кадры декодируются по необходимости; кэши изображений и отрисовки ограничены
  по байтам. NumPy больше не загружается при обычном проигрывании анимаций.
  Все кадры, качество и длительности анимаций сохранены.

### Maintenance

- Актуальные тесты собраны в `tests`; история разработки вынесена из рабочей папки.
- NumPy добавлен в список зависимостей; сборка использует закреплённые версии.
- Отделена чистая Git-копия от Dev; кэши и временные файлы сборки направлены на диск проекта.
- Готовый ZIP проверяется после распаковки без Python и исходников в путях запуска;
  список артефактов для release manager создаётся автоматически.

При подготовке будущего релиза владелец проекта переносит нужные изменения
из `Unreleased` в раздел с версией и датой. Этот файл не создаёт релизы или теги.
