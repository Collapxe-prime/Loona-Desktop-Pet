Loona Desktop Pet для Windows

Трей и автозагрузка:
Значок Loona в системном трее: ЛКМ возвращает питомца на монитор курсора,
ПКМ открывает меню. Значок может находиться под стрелкой скрытых значков.
«Вернуть Loona на экран» сбрасывает перетаскивание и инерцию.
В .exe пункт «Запускать при входе в Windows» включает/выключает автозагрузку,
по умолчанию выключенную. Сначала разместите всю папку сборки в постоянном месте;
после переноса включите пункт из нового .exe заново для обновления пути.
Повторный запуск .exe возвращает уже работающую Loona вместо запуска второй.
В Dev через Python автозагрузка недоступна, чтобы не регистрировать интерпретатор.

Версионирование и сборка:
VERSION содержит единый номер версии; CHANGELOG.md — историю изменений.
Инструкция: BUILDING.md. Локальная сборка: py -3.12 build.py.
Проверка подготовки без компиляции: python build.py --check.
Файлы dist, build, окружения, личные настройки и черновики исключены из Git.
Скрипт ничего не публикует и не выполняет команд Git.

Запуск: main.py в PyCharm или Start-Loona.cmd.
Настройки сохраняются в settings.json. ПКМ по Loona открывает меню.
ЛКМ позволяет перетаскивать и бросать её.
Без кнопок водите курсором по любой части спрайта: через 2 секунды
поглаживания появляются улыбка и сердечки.
Если гладить больше 4 секунд подряд и остановиться, проигрывается один
полный цикл злости. Остановка определяется по уходу курсора или паузе
движения 0,6 секунды. Перетаскивание, падение и печать отменяют эту реакцию.
Гримуар включается при печати и как случайное действие.
Сидение на окне длится 1–3 минуты и выпадает чаще других действий.
В сидячей позе сцепление с движущимся окном усилено.

Состав проекта:
• main.py и соседние модули — рабочее приложение.
• assets/revamp — текущие кадры и параметры анимаций.
• assets/petting-smile — улыбка и сердечки, включая GIF и исходный лист.
• assets/Loona.png и assets/animations — совместимость с прежним форматом.
• tests — актуальные проверки поведения, физики и переходов анимаций.
• .venv и .idea — окружение Python и настройки PyCharm.

Проверки из папки проекта:
.venv\Scripts\python.exe -m unittest discover -s tests
.venv\Scripts\python.exe main.py --self-test
Start-Loona.cmd --check
