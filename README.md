# Loona Desktop Pet

![Loona Desktop Pet](social-preview.jpg)

Loona поселится прямо на рабочем столе Windows. Пока вы занимаетесь своими делами, она гуляет по экрану, иногда пускается в бег, может присесть на окно или достать гримуар. А ещё замечает курсор и реагирует на набор текста.

Проведите курсором по Loona, чтобы погладить её: через пару секунд появятся улыбка и сердечки. Если гладить дольше четырёх секунд, а потом остановиться, она ответит одним циклом недовольства. Левым щелчком Loona можно схватить, перенести и бросить; правый откроет меню.

Окна для неё — часть рабочего стола, а не просто фон. Сидя на окне, Loona крепче держится за него, когда оно движется; иногда она скользит, падает и возвращает равновесие.

## Запустить Loona

Готовая сборка лежит в корне репозитория. Запустите `Loona-Desktop.exe` — Python для этого не нужен. Оставьте рядом папки `_internal` и `assets` и файл `VERSION`: без них приложение не запустится.

Настройки и журнал готовой сборки находятся в `%LOCALAPPDATA%\LoonaDesktopPet`.

Хотите запустить Loona из исходников? Откройте папку `Loona-Desktop` и запустите `Start-Loona.cmd`.

## Собрать приложение

Для сборки под Windows x64 нужен Python 3.12. Откройте PowerShell в папке `Loona-Desktop` и выполните:

```powershell
py -3.12 build.py
```

Приложение и ZIP-архив появятся в `dist`. Сборка остаётся локальной и сама ничего не публикует. Подробности — в [инструкции по сборке](Loona-Desktop/BUILDING.md), история изменений — в [CHANGELOG.md](Loona-Desktop/CHANGELOG.md).
