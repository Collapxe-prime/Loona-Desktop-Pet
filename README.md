# Loona Desktop Pet

![Loona Desktop Pet](social-preview.jpg)

Loona живёт на рабочем столе Windows. Она сама ходит по экрану, иногда бегает, садится на окна и время от времени достаёт гримуар. Если вы печатаете или водите курсором по её спрайту, Loona реагирует.

Погладьте её курсором — через две секунды появятся улыбка и сердечки. Если гладить дольше четырёх секунд, после остановки Loona проиграет один цикл злости. Правой кнопкой открывается меню; левой её можно перетащить или бросить.

На окнах Loona тоже сидит. Когда окно движется, она крепче за него держится, но иногда всё же соскальзывает и падает, а потом восстанавливает равновесие.

## Запустить Loona

Готовая сборка лежит в корне репозитория. Запустите `Loona-Desktop.exe` — Python для этого не нужен. Оставьте рядом папки `_internal` и `assets` и файл `VERSION`: без них приложение не запустится.

Настройки и журнал готовой сборки находятся в `%LOCALAPPDATA%\LoonaDesktopPet`.

Хотите запустить Loona из исходников? Откройте папку `Loona-Desktop` и запустите `Start-Loona.cmd`.

## Собрать приложение

Для сборки под Windows x64 нужен Python 3.12. Откройте PowerShell в папке `Loona-Desktop` и выполните:

```powershell
py -3.12 build.py
```

Приложение и ZIP-архив появятся в `dist`. Сборка остаётся локальной и сама ничего не публикует. Подробности — в [инструкции по сборке](Loona-Desktop/BUILDING.md), история изменений — в [CHANGELOG.md](Loona-Desktop/CHANGELOG.md).
