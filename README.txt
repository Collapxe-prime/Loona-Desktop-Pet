LOONA DESKTOP PET
Интерактивный питомец для рабочего стола Windows, написанный на Python.

О ПРОЕКТЕ
Loona живёт на рабочем столе, гуляет и реагирует на курсор, печать и прямое
взаимодействие. В репозитории находятся приложение, рабочие кадры анимаций
и сценарий локальной сборки для Windows.

ВОЗМОЖНОСТИ
- ПКМ по Loona открывает меню. ЛКМ позволяет перетаскивать её и бросать.
- Если удерживать курсор над питомцем, через две секунды появляются улыбка
  и сердечки. После поглаживания дольше четырёх секунд проигрывается один
  цикл злости; перетаскивание, падение или печать отменяют эту реакцию.
- Loona гуляет, иногда бегает, реагирует на печать, достаёт телефон и садится
  на окна.
- Взаимодействие с окнами учитывает инерцию, скольжение, падение и восстановление
  равновесия. Во время сидения сцепление с движущимся окном усилено.

ЗАПУСК
Запустите Start-Loona.cmd из папки проекта или откройте main.py в PyCharm.
Пользовательские настройки сохраняются в settings.json.

СБОРКА ДЛЯ WINDOWS
Для локальной сборки Windows x64 нужны Python 3.12 и инструкция в BUILDING.md.
Команда сборки: py -3.12 build.py. Она создаёт папку с Windows-приложением
и ZIP-архив локально; публикация GitHub Release выполняется отдельно.
