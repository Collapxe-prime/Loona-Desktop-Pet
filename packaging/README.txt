Loona Desktop Pet — Windows x64

Распакуйте ZIP целиком и запускайте Loona-Desktop.exe.
Не переносите EXE отдельно от _internal, assets и VERSION.
Установка Python не требуется.

ПКМ по Loona открывает меню; ЛКМ позволяет перетащить или бросить её.
Без нажатия кнопок водите курсором по спрайту: через две секунды появляются
улыбка и сердечки. После прекращения поглаживания дольше четырёх секунд
проигрывается один цикл злости.

Настройки и лог: %LOCALAPPDATA%\LoonaDesktopPet.
При обновлении заменяйте папку приложения, оставляя пользовательские данные.
Если нужно перенести настройки из исходного проекта, закройте Loona и скопируйте
свой settings.json в эту пользовательскую папку. Сборка его автоматически не копирует.
LOONA_DATA_DIR позволяет явно выбрать другую папку пользовательских данных.

Номер версии указан в VERSION, изменения — в CHANGELOG.md.
SHA256SUMS.txt содержит контрольные суммы файлов, BUILD-INFO.json — зависимости сборки.
Это неподписанная локальная сборка: подпись и публикация выполняются отдельно владельцем.
